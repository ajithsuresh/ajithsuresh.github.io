Research

Secure multiparty computation (MPC) lets several parties compute a function on their joint data while each input stays private. My work designs MPC protocols that are efficient enough for real deployments, and applies them where privacy is hardest: training and using machine learning models, and aggregating updates across many federated clients.

Themes

Practical MPC protocols

Mixed-protocol 2PC, honest-majority 3PC and 4PC, OT extension and circuit compilation.

Privacy-preserving machine learning

Frameworks for private inference and training: fixed-point arithmetic, truncation, lookup tables.

Secure federated learning

Aggregation that keeps client updates private and stays robust to poisoning, at large scale.

Featured work

Mixed-protocol two-party computation (ABY2.0)

ABY2.0, with Arpita Patra, Thomas Schneider and Hossein Yalame, improves mixed-protocol secure two-party computation, where a computation switches between arithmetic and Boolean sharing to use the cheapest representation at each step. It appeared at USENIX Security 2021.

Read Paper and talk

Secure federated learning at scale (WW-FL)

WW-FL combines secure computation with federated learning so that a large population of clients can train a model without exposing their updates. It appears at IACR CHES 2026, with Felix Marx, Thomas Schneider, Tobias Wehrle, Christian Weinert and Hossein Yalame.
